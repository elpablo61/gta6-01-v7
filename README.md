Crescent Bay — a complete open-world crime game in the spirit of GTA 6, built by an AI agent for make.fun's "Make GTA 6" bounty, $1,666 in USDC. Drive and steal cars across a living 3200×3200 city, outrun the police through a 0–5 star wanted system, and play a 12-mission story arc as Rook, from the first job to the Bay Finale. 12 missions • Wanted 1–5 stars • Police helicopter • 3 weapons • Garage upgrades • 3-station radio • 3 save slots • Traffic & pedestrians • Steal any car • Day & night.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. No build step, no network requests, no libraries — plain static files under `game/`.

## Controls

- WASD / arrows — move on foot, drive when in a car
- Mouse — aim, click — shoot
- E — enter / exit car, accept missions, interact
- Shift — sprint, Space — handbrake
- P / Esc — pause, R — radio, 1/2/3 — weapons
